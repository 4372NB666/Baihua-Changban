# 白话 · 长坂

> **BAIHUA — A Plain Tale of Changban**
>
> 正史不写，说书人讲了一千年。

一个关于**赵云七进七出**的东方史诗概念站。单文件、零依赖、离线可用。

非商业粉丝概念作品 · 原创视觉与文字 · 不含任何第三方游戏素材。

## 名字的来历

《**黑神话**：悟空》 ↔ 《**白话**：长坂》

| 黑 | 白 |
|---|---|
| 神话 | 白话 |
| 神魔小说 | 演义评话 / 话本 |
| 佛窟、金身、取经 | 汉简、帛画、朱砂、长坂 |

「白」是白袍、白马、白龙，长坂一日染成赤；「话」是话本、评话、说书人那张嘴——**「七进七出」本来就不是史书写的，是说书人讲出来的**。

正史《三国志·赵云传》关于这一战只有四十一字：

> 及先主为曹公所追于当阳长坂，弃妻子南走，云身抱弱子，即后主也，保护甘夫人，即后主母也，皆得免难。

没有七进，没有七出，没有青釭剑，没有五十余将。剩下的一千年，全是「白话」。
所以站内做了一个 **「说书人 · 白话 / 陈寿 · 史书」** 切换开关——一键从千军万马，切回那四十一字。名字不是贴上去的，是站点结构本身。

**Tagline：** 正史不写，说书人讲了一千年。
*What the history left out, the storytellers told for a thousand years.*

## 站内有什么

| 章节 | 内容 |
|---|---|
| Hero | 鎏金巨字「白话」、火光远山剪影、Canvas 灰烬粒子、竖排对联、鼠标微视差；「入阵」按钮 |
| 序章 | 竖排汉简叙事；**白话 / 史书** 双版本切换 |
| 七进 | 壹～柒 七幕卷轴，悬停金光与朱砂印；**入阵进度**七枚印随滚动点亮；**每幕附「史书按语」**，按 史／注／演 三级标注来源；每幕可点「下一幕 ↓」 |
| 影神图 | 赵 / 枪 / 剑 / 斗 / 话 **五帧**镂空大字卡；末帧「说书人」点出题旨 |
| 尾声 | 「一身都是胆」；七幕读毕后解锁「七阵已破」金光；可「回望卷首」 |

**可读性：** 底色由近黑提为暖墨褐、暗角减弱、三级文字色与金色标注整体提亮。小字对比度 **3.4:1 → 6.8:1**、金色标注 **4.0:1 → 5.3:1**（均过 WCAG AA），暗调东方史诗质感保留。

**交互细节：** 滚动进度条 · 导航吸顶 · 逐段揭示 · 响应式 · `prefers-reduced-motion` 支持 · 无外部请求。

**逐章引导：** Hero「入阵」→ 序章 → 七进 → 影神图 → 尾声，每章章末都有一枚可点击的「下一章」按钮；七幕每幕正文内另有「下一幕 ↓」，第七幕通往影神图；尾声可一键「回望卷首」。跳转统一平滑滚动并留出导航高度，开启系统「减少动态」时自动改为瞬时跳转。

**战场声：** 右下角「音」开关，**默认关闭**（遵循浏览器自动播放策略，必须点击后才会发声）。声音由 Web Audio API 实时合成——**金戈交击**（不谐和高频泛音 + 高通擦声）、提亮的战鼓、箭矢破空、马蹄三连、短号角，底噪是 620Hz 带通的「人马嘈杂」而非低沉风声；节奏约 0.7～1.2 秒一拍，随机组合不重复。**没有任何音频文件、没有外部请求、离线可用**；切走页面自动挂起，回来续播。不想听就不点，绝不自动播放。

**技术：** 原生 HTML + CSS + 一点点 Vanilla JS。视觉全部由 CSS 渐变、SVG 路径与 Canvas 手写生成，声音由 Web Audio 合成，**没有图片、没有音频文件、没有字体 CDN、没有框架、没有构建步骤**。双击 `index.html` 即可。

## 史料层级（考证部分）

写这一节的原则：**史料考证与史观解释分开**。七幕按语只标来源、不作论断；解释统一放在本节与「说书人」一帧。

| 层级 | 文献 | 长坂坡记了什么 |
|---|---|---|
| 史 | 陈寿《三国志·赵云传》正文 | 四十一字：弃妻子南走、云身抱弱子、保护甘夫人、皆得免难。**无**「七进」、无斩将、无青釭剑 |
| 注 | 裴松之注引《云别传》 | 或谓云已北去，先主曰「子龙不弃我走也」，顷之云至；另载汉水「一身都是胆」、截江夺斗 |
| 演 | 《三国演义》第四十一、四十二回 | 糜夫人投井、青釭剑（夏侯恩）、土坑红光、连斩五十余将、玄德掷子 |
| 话 | 后世评话、戏曲 | 概括出「七进七出」之名、「常胜将军」之称与白袍银枪的定型形象 |

**两处易混，已刻意分开处理：**
- 「一身都是胆」出自**汉水之战**（建安二十四年），不是长坂坡语，故只放在尾声，不混入七幕。
- 「七进七出」是后世对演义情节的**概括**，并非《三国演义》原文短语，更非史书文字。

## 本站的处理（解释部分）

本站不做史实复原，而是把「史书那四十一字」与「后来叠上去的一千年」并排摆着，让人看见中间那道缝——这也正是《白话 · 长坂》命名的由来。序章的「白话 / 史书」切换、七幕的三级按语，都是这一并置的具体实现。

《三国演义》《三国志》文本属公有领域；站内原创叙事文字与视觉设计见下节。
